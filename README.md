Entry for the [make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551): a program that writes one original one-line joke about working beside AI coding agents.

## Run

```sh
python3 main.py            # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is deterministic, standard library only, no network. It writes a single line (UTF-8, 1–280 Unicode code points) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
